# Lagunitas Website

A responsive website project built with **HTML, CSS, and JavaScript**, focusing on modern web design, interactive elements, and a clean user experience.

## 📌 Project Overview

This project demonstrates my practical frontend development skills through the design and implementation of a responsive website. It includes a structured HTML layout, custom CSS styling, and JavaScript functionality for interactive behavior.

## ✨ Features

* Responsive website layout
* Clean and modern user interface
* Structured HTML components
* Custom CSS styling
* JavaScript-based interactions
* Mobile-friendly design
* Interactive user experience

## 🛠️ Technologies

* **HTML5** — Page structure and semantic markup
* **CSS3** — Styling, layout, responsiveness, and visual design
* **JavaScript** — Interactive functionality and client-side behavior
